# Muhammad Sohaib Maqsood — Portfolio

Personal portfolio website for **Muhammad Sohaib Maqsood**, a data scientist and web developer.

Live site: https://Sohaib432002.github.io/PortfolioWebsite

## Features

- Responsive React frontend
- Project showcase with live demos and GitHub links
- Skills, certificates, services, FAQ, and contact form
- Downloadable CV
- WhatsApp contact button

## Tech stack

- React
- Tailwind CSS
- Framer Motion
- React Router

## Local development

```bash
npm install
npm start
```

## Production build

```bash
npm run build
```
